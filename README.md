# Лабораторная работа №3 по АиСД: Деревья

Шаблонная реализация структур данных «Двоичное дерево» и «АВЛ-дерево» на C++, а также рекурсивного парсера скобочной записи деревьев из стандартного потока ввода (`stdin`).

## Реализованный функционал

1. **Парсер скобочной записи (`TreeParser<T>`)**
   * Разбор строкового представления дерева из `stdin` с поддержкой положительных и отрицательных чисел.
   * Валидация синтаксиса (проверка парности скобок, корректности значений узлов и отсутствия лишних символов) с обработкой исключений (`std::runtime_error`) и безопасной очисткой памяти при ошибках.

2. **Двоичное дерево (`BinaryTree<T>` и `TreeNode<T>`)**
   * Шаблонная структура узла и дерева с поддержкой вставки (`add`), удаления (`remove`), поиска (`dfs`) и автоматического освобождения памяти.
   * Вычисление высоты исходного дерева (`getBinaryHeight`), построенного парсером.

3. **АВЛ-дерево (`AVLTree<T>` и `AVLNode<T>`)**
   * Построение сбалансированного дерева на основе исходного двоичного дерева (`build`).
   * Автоматическая балансировка при вставке с помощью малых и больших поворотов (LL, RR, LR, RL) и пересчётом высот.
   * Обход в ширину (`bfs`) на базе очереди.
   * Обходы в глубину (`printPreorder`, `printInorder`, `printPostorder`): прямой, центрированный и обратный.

## Структура проекта

```text
Laba_3_AISD/
├── AVLNode.h       # Шаблонная структура узла АВЛ-дерева (значение, высота, указатели)
├── AVLTree.h       # Реализация АВЛ-дерева, поворотов и методов балансировки
├── BinaryTree.h    # Шаблонный класс двоичного дерева (вставка, удаление, поиск)
├── TreeNode.h      # Шаблонная структура узла обычного двоичного дерева
├── TreeParser.h    # Парсер скобочной записи с проверкой корректности ввода
└── main.cpp        # Считывание из stdin, запуск обходов (BFS, DFS) и вывод результатов
```

## Сборка и запуск

Проект разработан в **Microsoft Visual Studio** (C++17 и выше).

### В Visual Studio
1. Откройте решение `Laba_3_AISD.sln`.
2. Выберите конфигурацию (`Debug` или `Release`) и платформу (`x64` / `x86`).
3. Соберите и запустите проект (`Ctrl + F5`).

### Через терминал (g++ / clang++)
```bash
g++ -std=c++17 -O2 main.cpp -o tree_lab
./tree_lab
```

## Пример работы программы

Программа считывает одну строку со скобочной записью из `stdin` и последовательно выводит:
1. Исходную строку ввода.
2. Высоту исходного дерева (до балансировки).
3. Высоту построенного АВЛ-дерева.
4. Обход в ширину (BFS).
5. Прямой обход в глубину (Pre-order).
6. Центрированный обход в глубину (In-order).
7. Обратный обход в глубину (Post-order).

**Ввод (`stdin`):**
```text
(8 (9 (5)) (1))
```

**Вывод (`stdout`):**
```text
(8 (9 (5)) (1))

3
3
8, 5, 9, 1
8, 5, 1, 9
1, 5, 8, 9
1, 5, 9, 8
```
